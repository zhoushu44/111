敏群 ERP · 本地打印代理（复刻 HSTIP / HUANSI 打印服务）

打印机配置

raw 模式：将 ZPL 指令通过 TCP 直发打印机（Zebra / TSC / Argox-ZPL仿真），最贴近老系统。system 模式：写临时文件经 Windows 打印（建议打印机端口设为 Generic / Text Only）。

串口扫描器（COM）

启用后，扫描到的条码经 SSE（/api/scanner/stream）推送给 Web；Web 端也可用键盘楔子扫码（无需本代理）。需先 npm i serialport。

状态

—

Web 标签打印页可切到「本地打印代理」模式，把标签发给本服务，由本服务真正输出到标签打印机（等价于老系统经 HUANSI 服务打印）。
