敏群商贸 ERP · 本地版 使用说明
================================

一、这个 exe 是什么
  一个 exe 同时做三件事，不需要再单独运行打印代理：
    1) 在本机打开与服务器版一模一样的 ERP 页面（页面已内嵌进 exe）；
    2) 数据仍从服务器实时获取（反向代理，不落地、不复制数据）；
    3) 点「直接打印（exe）」时，由本 exe 直接驱动本机标签打印机出纸。
  打印通道与原版 HSTIP_SHMQ 完全一致：把整张标签渲染成位图 → 转成打印机原生指令(PPLB)
  → 以 RAW 类型直接写入 Windows 打印队列，绕过驱动渲染。所以不需要设置纸张/缩放/份数，
  点一下就能打，且每台电脑输出一致。

  ★指令语言说明：本程序用 PPLB（Eltron EPL2 兼容，Argox CP-2140M 原生语言）：
  整张标签渲染成 1-bit 位图，用 N/q/Q/ZT/R/GW/P 指令下发，不依赖打印机字库，中文与二维码都能打。
  打印方向由 ZT（正常）/ZB（上下颠倒）控制，每张都下发，不依赖打印机存储的设置。

  ★ 本 exe 没有命令行黑窗口：双击后只在屏幕右下角托盘出现一个小图标，双击图标即打开页面。

二、使用前提
  1. 本机需能访问服务器（默认 http://195.72.185.32:7776）；
  2. 本机已安装标签打印机驱动，且在「设备和打印机」里能看到它；
  3. 打印机名必须与 config.json 里的 printerName 完全一致（见第五节）。

三、启动与退出
  启动：双击 敏群ERP本地版.exe
        → 右下角托盘出现图标，浏览器自动打开标签打印页
        → 页面地址：http://127.0.0.1:8788/print/labels
        → 登录 → 扫码/选料 → 点「直接打印（exe）」→ 标签机出纸
  退出：托盘图标上点右键 → 退出
  再次双击 exe：会提示「已在运行」，直接点开托盘图标即可

  托盘图标右键菜单：
    打开页面 / 打印测试标签 / 校准标签定位 / 打印机诊断 / 打开配置文件 / 查看日志 / 退出
    （双击托盘图标 = 打开页面）

  ★ 打印机诊断页：托盘右键「打印机诊断」，或浏览器打开 http://127.0.0.1:8788/__local/printers
    可以看到：配置的打印机名是否找到、本机所有打印机（名称/驱动/端口/状态/队列作业数），
    以及「打印测试标签」「校准标签定位」两个按钮——专门用来判断「提示已发送但没出纸」。

四、为什么本地版能打、服务器版打不了
  服务器版页面来源不是本机地址，浏览器会拦截「网页 → 本机(127.0.0.1)」的本地网络请求，
  所以点了打印没反应。本地版页面来源就是本机 127.0.0.1，不存在这个限制。

五、配置（config.json，与本 exe 同目录，改完用托盘菜单「退出」再双击 exe 生效）
  {
    "port": 8788,                             // 本地页面端口（被占用就改成 8789 等）
    "apiTarget": "http://195.72.185.32:7776", // 服务器地址（数据来源）★服务器换 IP 时必须改这里
    "open": true,                             // 启动后是否自动打开浏览器
    "homePath": "/print/labels",              // 启动后打开的页面
    "printer": {
      "port": 8790,                           // 打印服务端口（网页固定访问这个端口，一般不用改）
      "printerName": "Argox CP-2140M PPLB",   // ★ 必须与本机「设备和打印机」里的名字完全一致
      "label": {
        "widthMm": 70,        // 标签宽
        "heightMm": 40,       // 标签高
        "dpi": 203,           // 打印头分辨率（CP-2140M 为 203dpi）
        "gapMm": 2,           // 标签间隙（成卷间隙纸按实际缝隙填，定位靠它）
        "xOffsetMm": 16,      // 横向偏移补偿（内容整体偏左/偏右时调这个）
        "printDirection": "ZT", // ★ 打印方向：ZT=正常；标签上下颠倒改成 ZB
        "calibrateCmd": "xa\n" // 测纸（自动校准）指令，PPLB 为 xa
      }
    }
  }

六、排障（没有黑窗口，看日志）
  日志：exe 同目录 local-erp.log，托盘右键「查看日志」直接打开。
        启动时会记录：页面地址、数据源、打印端口、打印机名、内嵌页面数；
        打印机名对不上时会把本机全部打印机名写进日志。

  Q: 托盘图标双击没反应 / 提示「已在运行」？
  A: 说明已在运行，先到托盘找图标；找不到就是被折叠了，点托盘区的 ^ 展开。
  Q: 提示「页面端口 8788 无法监听」弹框？
  A: 端口被占用，改 config.json 的 port 后重新双击 exe。
  Q: 提示「打印代理未启动」？
  A: 通常是 8790 端口被占用——请先退出旧的 MQPrintAgent 打印代理再启动本 exe。
  Q: 点打印后打印机不动作？
  A: 看日志里的报错行。多数是打印机名跟 config.json 的 printerName 不一致；
     日志里会列出本机所有打印机名，照抄改配置再重启。
  Q: 页面提示「已直接发送 N 张到标签打印机」，但打印机就是不出纸？
  A: 这句只说明「作业已成功写进 Windows 打印队列」，不代表出纸。打开打印机诊断页
     （托盘右键「打印机诊断」）按下面顺序判断：
     ① 点「打印测试标签」：出纸且有内容 = 链路正常，问题只在页面数据；
     ② 出纸但空白 / 只有半张 = 位置问题：调 config.json 的 xOffsetMm（偏左加大、偏右减小），
        换纸后点「校准标签定位」；
     ③ 完全不出纸，且表里「队列作业数」不为 0 = 作业卡队列：打印机脱机/未连接/被暂停，
        到「设备和打印机」双击那台机把队列里的作业全部取消，检查电源与 USB；
     ④ 完全不出纸，队列为 0、状态"就绪" = 数据已送到设备但机器没认，多半是打印机语言
        模式不对（Argox 需为 PPLB），用 Argox 工具/机身设置确认；
     ⑤ 端口显示 FILE: / PORTPROMPT / nul = 端口配错，永远不会出纸，改成 USB/LPT/网络端口。
  Q: 登录页一直停在「正在检查系统初始化状态…」不动？
  A: 页面在等服务器的 /api/auth/bootstrap-status，说明本机连不上 apiTarget。
     先在浏览器直接打开 http://195.72.185.32:7776/api/auth/bootstrap-status 验证
     （应返回 {"initialized":true}）；打不开就说明服务器地址/网络变了，改 config.json 的 apiTarget。
  Q: 打印错位 / 内容偏左偏右 / 只打一半？
  A: 调 config.json 的 xOffsetMm（偏左加大、偏右减小）；换纸后点托盘「校准标签定位」。
  Q: 页面内容和服务器版不一致？
  A: 页面是构建时内嵌的，服务器前端更新后，用 local-app\build.ps1 重新构建本 exe 即可。
