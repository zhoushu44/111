## 一、问题现象

| 现象 | 说明 |
|---|---|
| 服务器版打印 | 点了没反应，标签机不出纸 |
| 本地版打印 | 页面提示「已直接发送 N 张到标签打印机」，但**打印机无任何动作** |
| 诊断结果 | 打印机名匹配（`Argox CP-2140M PPLB`）、端口 `USB001`、状态就绪、**队列作业数 0** |

**作业已被 Windows 打印队列接收（`printed:2`），但没有出纸** —— 指令已送达设备，但**设备不认这份指令**。

## 二、根因（已用证据定位）

### 2.1 打印机语言不匹配（核心）
原版遗留的真实打印文件 `原版HSTIP_SHMQ\1`（9977 字节，2019-11-29）逐字节解析，
确认原版使用 **PPLA**（Datamax DPL 血统），而新系统此前一直发 **PPLB/EPL2**。

原版帧结构（STX=0x02 前缀，浓度命令用 SOH=0x01）：

```
STX n            STX M0500        STX KW0267       STX O0220
STX V0           STX f303         SOH D            STX ICPgfx0
    └ 21 字节图形属性头：05 01 01 00 00 00 00 01 02 0C 01 2C 01 2C 01 00 00 00 FF FF FF
    └ 图形数据（约 9847 字节）
STX L            STX D11          STX A2           STX 1Y1100000170002gfx0
STX Q0001        STX E            STX xCGgfx0
```

### 2.2 图形数据是 PSOFT 组件的私有编码（未攻克）
对 `ICPgfx0` 后的图形数据做过全量检验：

| 检验 | 结果 | 结论 |
|---|---|---|
| gzip / deflate / raw inflate | 全部失败 | 不是标准压缩 |
| 数据熵 | **4.46 bits/byte** | 有结构，非加密 |
| 1 的占比 | 55.87% | 异常偏高（白底黑字应 8~25%） |
| 各 bit 位占比 | bit0=69.8%、bit6=77.4%、bit7=76.3%，其余≈44% | 位分布不均 |
| 相邻行相似度（行宽 1~128 全扫） | 最高仅 16.02%，无峰值 | 找不到正确行宽 |
| 重复周期 | 无 | — |

**结论**：该图形数据是 `hsReport19_3.bpl` 内 PSOFT 条码组件的**私有编码**，无公开文档。
此前按「裸位图」复刻的做法**不成立**，这也是照抄后仍不出纸的原因。

### 2.3 `D` 指令语义误用（已修）
PPLB 官方指令表：`D` = **热感头浓度（0~15）**，`Z` 才是 Set Print Direction。
原代码写 `D1`（最低浓度）并注释为「固定方向」，且该值写入打印机 EEPROM，导致打印极淡。
**原版样本用的是 `D11`**。

## 四、复刻路线（按优先级，做到能用为止）

### 路线 1：确认打印机 Emulation，切到匹配的语言 ★先做
- 出打印机自检页（按住走纸键开机），看印的是 **PPLA** 还是 **PPLB**
- 若是 **PPLB** → 改 `config.json` 的 `language` 为 `"PPLB"`，**立即能用**（代码已就绪）
- 若是 **PPLA** → 走路线 2

### 路线 2：直接复用厂商官方 DLL（最贴近"直接复刻"）
Argox 官方 `Winpplb.dll`（BWIN-CAPI）提供完整原生产能，是厂商推荐用法：

| 函数 | 作用 |
|---|---|
| `B_CreatePrn` / `B_ClosePrn` | 建立/关闭打印作业 |
| `B_Get_Graphic_ColorBMPEx` | **BMP → 打印机图形**（替掉自研编码） |
| `B_Set_Darkness` | 设置浓度 |
| `B_Set_Labgap` / `B_Set_Labwidth` | 标签间隙/宽度 |
| `B_Prn_Text_TrueType_Uni` | 直接打 Unicode 文字 |
| `B_Bar2d_QR` | 直接打二维码 |
| `B_Print_Out` | 出图 |

→ 用该 DLL 重写打印出口，**不再自己拼指令**，从根上绕开私有编码问题。

### 路线 3：字节级复刻（需现场抓包）
用 Argox 官方工具在同机型上抓一份真实打印指令流，与我们的输出逐字节比对，
反推出图形编码规则后精确复刻。

1. 整个 `本地ERP版` 文件夹拷到新电脑（放 `D:\` 这类普通目录，别放 `C:\Program Files`）
