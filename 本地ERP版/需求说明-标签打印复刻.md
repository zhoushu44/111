# 标签打印复刻需求说明（本地 ERP 版）

**日期**：2026-09-29
**模块**：敏群商贸 ERP — 标签打印
**目标**：**把原项目（HSTIP_SHMQ）的打印能力完整复刻进来**，先做到「点击就能打出标签」

---

## 一、问题现象

| 现象 | 说明 |
|---|---|
| 服务器版打印 | 点了没反应，标签机不出纸 |
| 本地版打印 | 页面提示「已直接发送 N 张到标签打印机」，但**打印机无任何动作** |
| 诊断结果 | 打印机名匹配（`Argox CP-2140M PPLB`）、端口 `USB001`、状态就绪、**队列作业数 0** |

**作业已被 Windows 打印队列接收（`printed:2`），但没有出纸** —— 说明指令已送达设备，但**设备不认这份指令**。

## 二、根因分析（已用证据定位）

### 2.1 打印机语言不匹配（核心）
原版遗留的真实打印文件 `原版HSTIP_SHMQ\1`（9977 字节，2019-11-29）经逐字节解析，
确认原版使用 **PPLA**（Datamax DPL 血统），而新系统此前一直发 **PPLB/EPL2**。

原版帧结构（STX=0x02 前缀，浓度命令用 SOH=0x01）：

```
STX n            STX M0500        STX KW0267       STX O0220
STX V0           STX f303         SOH D            STX ICPgfx0
    └ 21 字节图形属性头：05 01 01 00 00 00 00 01 02 0C 01 2C 01 2C 01 00 00 00 FF FF FF
    └ 图形数据（约 9847 字节）
STX L            STX D11          STX A2           STX 1Y1100000170002gfx0
STX Q0001        STX E            STX xCGgfx0
```

### 2.2 图形数据是私有编码（**未攻克**）
对 `ICPgfx0` 后的图形数据做过完整分析：

| 检验 | 结果 | 结论 |
|---|---|---|
| gzip / deflate / raw inflate | 全部失败 | 不是标准压缩 |
| 数据熵 | **4.46 bits/byte** | 有结构，非加密 |
| 1 的占比 | 55.87% | 异常偏高（白底黑字标签应 8~25%） |
| 各 bit 位占比 | bit0=69.8%、bit6=77.4%、bit7=76.3%，其余≈44% | 位分布不均，非普通位图 |
| 相邻行相似度（1~128 字节全扫） | 最高仅 16.02%，无突出峰值 | 找不到正确行宽 |
| 重复周期 | 无 | — |

**结论**：该图形数据是 **PSOFT 条码组件（`hsReport19_3.bpl` 内）的私有编码格式**，
没有公开文档，**无法可靠反推**。此前按「裸位图」复刻的做法是错的，这也解释了为何照抄后仍不出纸。

### 2.3 `D` 指令语义误用（已修）
PPLB 官方指令表：`D` = **Heat Setting（打印浓度 0~15）**，`Z` 才是 Set Print Direction。
原代码写 `D1`（最低浓度）并注释为「固定方向」，且该值写入打印机 EEPROM，
导致后续打印极淡。**原版样本用的是 `D11`**。

## 五、下一步技术路线（PPLA 图形编码）

只要能拿到**原版工具生成的真实指令流**（同机型、同标签尺寸），即可：
1. 用我们自己的位图替换其中的图形数据段，逐字节比对找出编码规则；
2. 或直接复用 PSOFT 编码逻辑（若能从 `hsReport19_3.bpl` 中定位到该函数）。

也可考虑：**用 Argox 官方 DLL（`Winpplb.dll` / `BWIN-CAPI`）** 替代自研编码 ——
该 DLL 提供 `B_Get_Graphic_ColorBMPEx`（BMP→打印机图形）、`B_Set_Darkness`、`B_Print_Out` 等完整能力，
是厂商推荐用法，比反推私有格式可靠。

## 七、换电脑测试步骤

1. 整个 `本地ERP版` 文件夹拷到新电脑（放 `D:\` 这类普通目录，别放 `C:\Program Files`）
2. 确认新电脑：已装标签机驱动、能访问服务器 `http://195.72.185.32:7776`
3. 打开 `config.json`，把 `printerName` 改成该机「设备和打印机」里的**准确名字**
4. **先退出旧的 MQPrintAgent 打印代理**（否则 8790 端口冲突）
5. 双击 `敏群ERP本地版.exe` → 托盘图标出现 → 自动打开页面
6. 托盘右键 → **打印机诊断** → 点「打印测试标签」
7. 如不出纸，把诊断页截图 + `local-erp.log` 发回
